# Rust 同步客户端

完成内容见[公共同步客户端任务](../../../common/tasks.md#同步客户端)。开发环境、检查命令和启动命令见 [Rust 路线](../README.md)，必须在本目录执行。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `src/main.rs` | 解析 `--url` 并启动客户端 |
| `src/lib.rs` | 请求构造、响应解析和交互循环 |
| `tests/connection.rs` | 连接与请求处理集成测试 |

## 开发说明

从 `lib.rs` 的请求函数和命令分派开始，保持命令行解析集中在 `main.rs`。实现任务时优先扩展命令、请求体构造和令牌保存逻辑，不需要引入异步 HTTP 客户端。

启动后的操作见[共通交互](../../../common/tasks.md#共通交互)。

## echo 多行输入

输入 `echo` 后逐行输入正文。单独一行 `.` 结束并保留正文的行尾换行；
单独一行 `.end` 结束并移除最后一个行尾换行。立即输入结束标记可发送空文本。
正文中以 `.` 开头的行需要额外加一个点，例如 `..` 表示正文的 `.`，
`..end` 表示正文的 `.end`。空行、空格和 Unicode 均保留。
输入结束标记前遇到 EOF 会退出客户端，不发送未完成的正文。

例如输入 `echo`、`你好`、`RM`、`.end`，请求为 `{"text":"你好\nRM"}`；
使用 `.` 结束则请求文本保留最后一个换行。
